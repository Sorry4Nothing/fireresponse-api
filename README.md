# FireResponse API

Backend mit Admin-Panel für FireResponse, die App für Jugend- und Kinderfeuerwehren im Kanton Zürich: Termine aus Lodur, Ja/Nein-Anmeldung, Push und Auswertung im Admin-Panel.

Die Android- und die iOS-App liegen in eigenen Repositories und halten sich an denselben API-Vertrag.
